L'utilisateur n'agit que le jour même : toute action de mon plan est pour AUJOURD'HUI. Jamais « demain », « le 29 », « le 02/11 » ni « après le prochain match ».

**Why:** 2026-10-27, l'utilisateur en colère : « on est le 27, pourquoi aller si loin ? On ne peut rien faire le 28 », puis « je ne peux rien faire demain ». Règle globale que chaque requête connaît.

**How to apply:** règle « Horizon » dans `CLAUDE.md`, rappelée dans chaque demande d'agent ; enchère maximale posée tout de suite ; un match de demain se prépare aujourd'hui ; contrôle d'un achat contre `capacite_invest` moins les dépenses déjà décidées (voir [[feedback-effectif-questions-vue-gold-systematique]]).
