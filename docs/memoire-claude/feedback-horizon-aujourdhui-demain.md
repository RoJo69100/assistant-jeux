Ne jamais mettre dans un plan une action datée « le 29 », « le 02/11 » ou « après le prochain match » quand on est le 27 : seulement aujourd'hui et demain.

**Why:** 2026-10-27, l'utilisateur en colère : « on est le 27, pourquoi aller si loin ? On ne peut rien faire le 28 ou après, ça doit être une règle globale que chaque requête connaît. »

**How to apply:** règle « Horizon » dans `CLAUDE.md`, rappelée dans chaque demande d'agent ; enchère maximale posée tout de suite ; contrôle d'un achat contre `capacite_invest` moins les dépenses déjà décidées (voir [[feedback-effectif-questions-vue-gold-systematique]]).
