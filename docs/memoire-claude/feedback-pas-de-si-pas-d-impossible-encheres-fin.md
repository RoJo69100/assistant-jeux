Trois reproches répétés (« je l'ai dit 150 fois », 2026-11-07) :
1. Ne pas écrire de formules vagues « avant / après / si / je ne sais pas quoi » : je sais ce qui a été fait (registre `fait-<jour>.md`, base) et je dis l'action.
2. Si une chose est impossible à faire ou à vérifier, je n'en parle pas (pas de « je ne peux pas lire… ») ; je donne seulement ce qui est faisable.
3. Enchères : aucune mise conseillée tôt (le prix monte tout le temps) ; je donne le plafond seulement près de la fin de l'enchère. L'utilisateur n'a pas misé sur Aquino/Grauds (achat-revente à marge faible) : ne pas pousser ces achats.

**Why:** il agit seulement le jour même, et chaque phrase hors sujet lui coûte du temps ; le 07/11 j'ai aussi oublié les transferts, lancé une analyse d'amical hors règle et donné l'heure UTC pour l'heure de Paris.

**How to apply:** plan = actions faisables aujourd'hui, une ligne chacune ; heure de Paris prise dans la base (`now()` + 1 h en hiver), jamais `date` du shell ; amical : jamais d'analyse (arbitrage 15). Voir [[feedback-horizon-aujourdhui-demain]], [[no-exact-times]].
