# Profil idéal par poste

Sources : skills basketvibe-joueurs [M§2.2, §5.2, §6.2.1] et basketvibe-tactique [M§7.1] ; joueurs observés dans nos données (marché : `silver.bv_transfer_auctions`, compétences exactes ; adversaires : `gold.bv_match_opp_focus`, stats de ligue). Mis à jour le 2026-10-18.

**Rappel** : en match, seuls comptent l'**emplacement** dans le cinq et la **taille** par rapport à cet emplacement ; le libellé de poste ne compte pas [M§6.2, Dev 2026-09-10]. Le PS utilise les poids ci-dessous, indicatifs [Dev 2026-09-17].

| Poste | Compétences clés (attaque / défense [M§7.1]) | Poids du PS les plus forts [M§2.2] | Taille pleine efficacité [M§6.2.1] | Profils qui marchent [M§7.1] |
|---|---|---|---|---|
| **PG** | Dribble + Passe / Défense | 2 pts, 3 pts, Passe, Dribble, Défense (15 chacun) | 180–200 cm | Meneur passeur (Passe, Dribble) ; pénétrateur (Dribble, 2 pts, Athlétisme) |
| **SG** | 3 pts + 2 pts / Défense | 2 pts, 3 pts, Dribble, Défense, Athlétisme (15) | 190–200 cm (98 % à 185 et à 205) | Scoreur arrière (3 pts, Dribble) ; 3-and-D (3 pts, Défense) |
| **SF** | 2 pts + 3 pts / Défense | 2 pts, 3 pts, Défense, Athlétisme (15) | 195–205 cm | 3-and-D ; défenseur extérieur (Défense, Athlétisme) |
| **PF** | 2 pts / Défense + Rebond | 2 pts, Défense, Rebond, Athlétisme (15) | 200–210 cm | Intérieur finisseur (2 pts, Rebond) ; rebondeur (Rebond, Défense) |
| **C** | 2 pts + Rebond / Défense + Rebond | 2 pts, Défense, Rebond, Athlétisme (15) | 205–215 cm et plus | Rebondeur dur au mal ; grand pivot athlétique (marque beaucoup même avec peu de tir [Com 2026-09-14]) |

L'endurance n'agit pas en match (fatigue et blessures seulement) [M§7.1] ; elle pèse 10 dans le PS de tous les postes.
